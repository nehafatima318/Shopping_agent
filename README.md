# Shopping_agent
• Developed a multi-modal AI shopping assistant using LangChain and LangGraph agents, integrating LLMs from Groq
and Google Gemini, with tool calling and agent orchestration for product search, rating retrieval, image-based
product identification, and order placement.
• Integrated vision-language models to extract product attributes from uploaded images and translate them into
database search queries; built a SQLite-backed product and order management system with dynamic filtering by
keywords, price range, and organic preferences.
• Implemented rating-based filtering for personalized recommendations and a human-in-the-loop workflow requiring
explicit user confirmation before checkout; delivered an interactive Streamlit interface.
